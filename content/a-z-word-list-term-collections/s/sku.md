## SKU

Avoid using the abbreviation *SKU* (pronounced "skew") to describe an offering type for a product, because it's jargon. Instead, use a term that's precise and well understood, like *subscription*, *edition*, *version*, or *tier*.

If you need to use *SKU* because customers expect it, you don't need to spell it out. If you choose to spell it out, use *stock-keeping unit (SKU)* at first mention.

**Examples**  
Pricing depends on the subscription level.  
Choose a storage tier.  
For **SKU**, select an option. Remember that **Standard** has more features than **Basic**.
