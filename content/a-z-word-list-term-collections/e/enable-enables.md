## enable, enables, enabled

Avoid using *enables* (or *allows* or *lets*) to refer to things that technology makes possible for the customer. Rewrite to focus on what's important or possible from the customer's point of view. For example, use "Write, draw, and take notes on webpages by using Microsoft Edge" instead of "Microsoft Edge enables you to write, draw, and take notes on webpages."

Don't use *enable* to describe making a feature, setting, command, or function available, unless you need to match the UI. Use *turn on*.

Don't use *enabled* to describe the state of a feature, setting, command, or function, unless you need to match the UI. Use *on*, *turned on*, or *available*.

In UI, avoid using **Enable** / **Disable** as labels for a toggle that controls availability. Use **On** / **Off**, if those words are accurate for the feature or capability. Or use more specific words, such as **Show** / **Hide**, **Add** / **Remove**, or **Allow** / **Block**.

**Example**  
After your administrator turns on the feature, verify that the button is available.
