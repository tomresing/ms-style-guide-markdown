## dialog box, dialog, dialogue

In UI, a dialog box is a temporary interface that appears as a confirmation or a request for information within a [window](../w/window). The user selects a button to close it.

When you need to refer to the UI element for clarity, use *dialog box*. Don't use *dialog*, *dialogue box*, or *pop-up window*. For a general audience, you might not need to include *dialog box* after the name.

To refer to conversation, use the spelling *dialogue* because it's more common than *dialog*, according to the Merriam-Webster Dictionary.

## Examples

- In the dialog box that appears, select **Yes** to accept your changes.
- In **Confirm your changes**, select **Yes**.
- Select **OK** to close the dialog box and return to the **Create your server** pane.
- Start a dialogue with your support team.
