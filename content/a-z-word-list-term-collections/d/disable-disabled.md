## disable, disables, disabled (functionality)

In descriptions of product functionality, avoid *disable*, *disables*, and *disabled* to prevent an association with accessibility terms.

Don't use *disable* to describe making a feature, setting, command, or function available, unless you need to match the UI. Use *turn off*.

Don't use *disabled* to describe the state of a feature, setting, command, or function, unless you need to match the UI. Use *off*, *turned off*, or *not available*.

In UI, avoid using **Enable** / **Disable** as labels for a toggle that controls availability. Use **On** / **Off**, if those words are accurate for the feature or capability. Or use more specific words, such as **Show** / **Hide**, **Add** / **Remove**, or **Allow** / **Block**.

**Example**  
If the command prompt isn't available, your network administrator might have turned off this feature.
