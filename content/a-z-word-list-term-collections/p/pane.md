## pane

Use *pane* to refer to the separate areas of a split window. For example, a list of resources might appear on one pane and the contents of a selected resource on another pane.

If a pane isn't labeled in the UI, use lowercase for the name that describes it. If a pane is labeled in the UI, use bold on the name.

Use the preposition *in* when you refer to a pane.

Use *open* and *close* as verbs with panes.

**Examples**  
Open the annotation pane.  
In the **Score** pane, select an asset to view details.

If you're creating UI text, use sentence-style capitalization for pane names.
