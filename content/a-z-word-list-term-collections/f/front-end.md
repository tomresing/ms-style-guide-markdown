## front end, front-end

In content for a general audience, don't use as a synonym for the desktop interface to a database or server. Instead, refer to the program by name, or use a term like *interface*, *program*, or *app*.

In content for a technical audience, it's OK to use *front end* (noun) and *front-end* (adjective that precedes a noun) if it's necessary for accuracy.

**Examples**  
The server sends information to the web interface.  
Front-end applications call back-end APIs.
